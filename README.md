# End-to-end episodes, post-training and inference deployment for cosmos 3 edge

These are the supporting scripts for our cosmos deployment tutorial.

Contents:
- `cosmos_train`: training job wrappers for training cosmos policies on viam
- `episodes`: scripts for generating simulated actions and creating random sets of them for training

If you're working with these, definitely the viamrobotics/viam-agentic-kit marketplace, which provides mcp and agent support for this tutorial.
